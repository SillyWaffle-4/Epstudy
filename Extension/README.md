# EPStudy Sync Extension

This is an unpacked Chrome/Edge extension for EPStudy. It has no popup. It syncs through the EPStudy website page.

## Install

1. Open `chrome://extensions`.
2. Turn on Developer mode.
3. Click Load unpacked.
4. Select this `extension` folder.
5. If you open EPStudy from `index.html`, enable Allow access to file URLs for this extension.

## Use

Keep EPStudy open, then open signed-in tabs for:

- Canvas, defaulting to `eastsideprep.instructure.com`
- TeamSnap schedule pages for each team you want tracked
- Membean

The extension syncs automatically every 10 minutes. You can also use Settings -> Extension Sync -> Ask Extension To Sync in EPStudy.

## What It Sends

- Canvas assignments and dated todo items found on signed-in Canvas pages
- TeamSnap games, practices, matches, tournaments, and events across multiple team tabs
- Membean weekly requirement as 3 sessions of 10 minutes, creating a task for the remaining sessions due Saturday morning
