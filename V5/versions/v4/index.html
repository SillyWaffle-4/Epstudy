EPStudy Guide

Plan your day without hunting through five tabs.

EPStudy brings tasks, schedule blocks, focus time, lunch, and reminders into one workspace that adapts to how you actually study.

V2 Workspace

Quick Setup

You can change these later in Settings.

SS

Smart Suggestion

EPStudy looks at real due dates, priority labels, overdue work, and nearby deadlines. It keeps suggestions focused by ignoring work too far in the future or too old to matter.

FT

Focus Timer

Load any task into the timer, pick a preset or custom length, and use Focus Shield to block distracting sites while you work. The timer resets back to no selected task when it ends.

CA

Calendar + Schedule

The calendar shows Canvas work and external events without duplicates. Week view stays on the current week, and the school schedule highlights the current period when school is in session.

Recommended Setup

Open Settings first.Choose Middle Schooler or Upper Schooler, set your reminders, and keep only the dashboard sections you actually use.
Use Sync for imports.Connect Canvas or other external services from the Sync tab when you want outside tasks and events pulled in.
Start from Smart Suggestion.Use the suggestion as your first task, dismiss anything you do not want to see, or open More Info to jump back to Canvas when a link is available.
Use the timer when you are ready.Load a task into either focus timer, start a session, and let notifications keep external events visible without putting them in your task list.

Features Worth Knowing

Change course colorsIn Settings, each course has a color picker. Those colors carry into tasks and calendar cards so your classes are easier to scan.
Dashboard expansionSettings lets you choose which dashboard sections start as compact buttons, so big panels stay out of the way until you need them.
Skins can do more than colorsSome skins change the whole mood of the page, including animated or visual backgrounds. Use Show Skins to turn those effects on or off.
Music is optionalPick a chill, study, or lofi track in Settings, import your own audio, or choose None if you want EPStudy quiet.
External events stay on the calendarImported external items are treated as events, not homework. They appear on the calendar and notifications page when they are coming up soon.
Reset is seriousThe Reset button clears tasks, calendar data, settings, notifications, and saved dashboard state. Use it only when you really want a fresh start.

Best daily flow: check Smart Suggestion, glance at Schedule Awareness, load one task into the timer, then use the calendar when you need the bigger picture.

Canvas Token Setup Guide

A Canvas token lets EPStudy directly read your active courses, assignments, and calendar events. Keep it private.

  1. Open eastsideprep.instructure.com and sign in.
  2. Click Account or your profile icon in the left Canvas navigation.
  3. Open Settings, then scroll to Approved Integrations.
  4. Click + New Access Token. Set Purpose to EPStudy and choose a short expiration date if possible.
  5. Click Generate Token.
  6. Copy the token immediately. Canvas only shows it once.
  7. In EPStudy, keep the domain as eastsideprep.instructure.com, paste the token, then click Sync Canvas Todo & Schedule.
  8. If sync fails because of browser CORS, keep the private proxy option enabled.

How EPStudy Stores Your Info

  1. Website data: tasks, courses, dashboard settings, notifications, timers, and blocked-site lists are stored in this browser's localStorage under EPStudy's storage key.
  2. Sync data: Canvas, lunch, course settings, and Focus Shield state stay on this device in your browser storage unless a connected service is being queried live.
  3. Canvas token: if you paste a Canvas API token into the page, it stays in the page field unless your browser autofills/saves it. EPStudy does not upload it to a database.
  4. Contact form: sending support opens your email app with the message addressed to both support emails. The site itself does not silently send mail.
  5. Reset: the Reset button clears EPStudy website data from this browser.
